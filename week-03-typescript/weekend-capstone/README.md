# Weekend 3 Capstone — Typed REST API Client Library

Build a typed REST API client. Wrap `fetch` with:

- Generic methods: `get<T>()`, `post<T, B>()`
- Typed error handling
- Retries with backoff
- Request/response interceptors

Publish it as a tiny **npm package** (private is fine — what matters is the package shape).

You'll use a pattern just like this in real React apps.

## Run it

```bash
npx tsx src/index.ts
```

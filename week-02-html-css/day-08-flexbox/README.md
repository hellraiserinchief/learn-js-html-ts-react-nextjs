# Day 8 — Flexbox

**Reading (45 min):** [CSS Tricks — Complete Guide to Flexbox](https://css-tricks.com/snippets/css/a-guide-to-flexbox/) — the canonical reference.

**Practice (60 min):** Play [Flexbox Froggy](https://flexboxfroggy.com/) end-to-end. Don't skip it because it looks like a game — it's the fastest way to internalize the model.

## Key concepts

- Flexbox is **1D** — items flow in one direction (row or column).
- `justify-content` aligns on the **main** axis; `align-items` on the **cross** axis.
- `flex: 1` is shorthand for `flex: 1 1 0%` — grow, shrink, basis.
- `gap` works in flex now — stop using margins for spacing between items.

# Weekend 2 Capstone — Rebuild a Real Landing Page

Pick a real product landing page (Linear, Stripe, Vercel, Notion). Rebuild it from scratch with **semantic HTML and modern CSS** — no framework.

## Must include

- Responsive layout (Grid + Flexbox)
- Dark mode toggle (single `data-theme` attribute swap)
- At least one `<dialog>`
- Accessible forms (label every input, correct `type`)
- One container-query-responsive card

## Ship it

Push to GitHub. Run a Lighthouse audit — aim for accessibility > 95.

This artifact alone shows you can be trusted with frontend.

## Run it

```bash
pnpm dlx serve .
```

A starter `index.html` and `styles.css` are included.

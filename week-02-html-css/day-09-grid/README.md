## Key concepts

- Grid is **2D** — rows and columns simultaneously.
- `grid-template-columns: repeat(auto-fit, minmax(250px, 1fr))` gives you a responsive grid in one line, **no media queries**.
- Named grid areas make complex layouts readable.
- `subgrid` lets nested grids inherit tracks from the parent.

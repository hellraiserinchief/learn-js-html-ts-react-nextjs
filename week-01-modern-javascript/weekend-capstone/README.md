# Weekend 1 Capstone — Node CLI Report Tool

Build a Node CLI tool that:

1. Fetches data from a public API (your choice)
2. Transforms / aggregates it
3. Writes a report file (JSON, CSV, or Markdown)

## Requirements

- ES modules (`"type": "module"`)
- `async`/`await`
- At least one **class**
- At least one **generator**
- ~150–200 lines

## Ship it

Push to GitHub. This is your proof-of-fluency artifact for Week 1.

## Run it

```bash
node cli.js --out report.json
```

A `cli.js` skeleton is included to start from.

# Day 2 — Functions, Arrow Functions, Destructuring, Spread

**Reading (45 min):** [Exploring JS — Callables](https://exploringjs.com/js/book/ch_callables.html), [Destructuring](https://exploringjs.com/js/book/ch_destructuring.html).

## Key concepts

- Arrow functions: lexical `this` (inherit from enclosing scope), no `arguments` object, can't be used as constructors.
- Default parameters, rest parameters (`...args`), spread operator (`...arr`).
- Object/array destructuring with renaming, defaults, and nesting.

## Exercise

Write a function that takes a deeply nested user object and returns a flattened summary using **only destructuring** (no dot access). Then refactor a small class using arrow methods.
